🎯 COMMANDES ESSENTIELLES

  Setup GitHub
  ────────────
  git init
  git add .
  git commit -m "Initial commit: Shelf MCP Server"
  git remote add origin https://github.com/YOU/shelf-mcp-server.git
  git push -u origin main

  Smithery
  ────────
  smithery login                    # Login
  smithery deploy                   # Déployer
  smithery publish shelf            # Publier
  smithery list                     # Lister vos serveurs
  smithery logs shelf               # Voir les logs

  Test Local
  ──────────
  pip install -r requirements.txt   # Installer dépendances
  python shelf_mcp_server.py        # Lancer le serveur
  smithery dev                      # Mode développement
  smithery validate                 # Valider config

  Installation
  ────────────
  smithery install shelf --client claude     # Installer localement
  smithery uninstall shelf                   # Désinstaller
